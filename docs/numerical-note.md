## 对象和证据边界

令 `N_p(x) = (sum_i |x_i|^p)^(1/p)`，三项亏损为 `S-T`，两项亏损之和为 `G=2S-P`，其中 `S` 为三个向量范数之和，`T` 为总和范数，`P` 为三个两两和范数之和。

循环三元组为 `(-t,1,1),(1,-t,1),(1,1,-t)`，定义

```
A = (t^p+2)^(1/p)
B = (2|1-t|^p+2^p)^(1/p)
R(p,t) = (3A-3^(1/p)|2-t|)/(6A-3B)
K_p = sup_{t in [1/2,2]} R(p,t)
E(p,q) = (1-q)/(2(1-((1+q^p)/2)^(1/p)))
```

代码中的每个比较必须严格通过区间包围或精确有理数运算，优化器只生成待检验输入。证书验证器没有检查所有解析推理、上游 Lean 依赖、Lean 内核或平台提交。

Arb 的包围数及精度语义见 [python-flint 0.9.0 官方文档](https://python-flint.readthedocs.io/en/latest/arb.html)。参数以有理数字符串读入，端点用包围并集形成区间；没有把机器浮点小数当作精确输入。跨越 t=1 时，`|1-t|^p` 利用底数非负和单调性构造含零的包围，避免把含零球体误当成严格正数。

参考来源：cutoff 32 目标 `6e8430ce-7c32-4b82-9a1b-d7fcd67fdeb3`，接受解 `2d248eb1-4938-4dee-8392-df24d2c70f2f`，作者 @bwdaugherty；该工作建立在 Ezzeri Esa / savarin 的 Hlawka–Schatten 构造及 cutoff 50 工作之上。具体来源和文件哈希见 `sources/provenance.json`。本次新贡献是窗口数据、精确线性证书、区间验证器及下面的参数适配，不是发明原归约路线。

## 1. 标量窗口

取 `c=56/125=0.448`，`q=1927/5000=0.3854`。`scalar.json` 把 p 区间完整划分成 1124 个闭区间；每个区间保存一个精确有理 t，验证器检查 `E(p,q)<R(p,t)` 和 `cp<R(p,t)`。因此对每个实数 p 都有 `E(p,q)<K_p` 和 `cp<K_p`，不需要证明选择的 t 是最大点。

`cyclic-upper.json` 则覆盖整个 p、t 定义域，在每个矩形检查分母严格为正，以及 `R(p,t)<p/2`。这推出 `K_p≤p/2`。两个覆盖分别独立检查边界、顺序、重叠及缺口。

## 2. 粗定位：用精确线性证书替代固定 K=14.336

沿用来源中的正规化与三维归约，把假设反例缩放成 `S=3`、每个单项范数 `N_j≤T`。包络给出 `1≤T<3q=1.1562`；反例给出 `KG<3-T`，且 `G≥0`。用新的统一下界 `k0=c*(127/4)=14.224`，得到

```
k0 G + T < 3,
G < 2/k0,
N_j > 3-2*(3q).
```

对任意两两和，范数不超过 `2*(3q)`，最大坐标与范数之差不超过 `2*(3q)*(1-3^(-1/p))`。验证器在最坏端点检查该量小于 `0.08`。

三对向量所选的坐标必须不同：若两对共享向量且选择相同坐标，同号时带符号的总坐标至少为 `3-2G-0.16>T`；异号时该共享向量范数最多为 `G+0.08<3-2T`。这些界的数值条件也在验证器中检查。由符号与坐标置换可以令每一对的主坐标落在对应的互补位置。

线性模型的变量是 9 个坐标、3 个单项范数、3 个两两和范数、总和范数 T。约束仅使用三角不等式、单坐标界、正规化、主坐标误差和 `k0 G+T≤3`。模型可以包含并非真实范数数据的点；这只会使推论更保守。

第一阶段的 18 个线性对偶证书证明每对主坐标非负、至多为 3，且其他两个坐标的绝对值至多为主坐标的一半。由凹函数估计，范数超过主坐标的尾项最多为 `6*2^(-p)/p<10^-5`。加入此已检验的更强线性约束后，另 18 份对偶证书推出原粗盒子：对角项 `[-1.158,-0.555]`，其他项 `[0.79,1.158]`。

每份对偶证书使用精确 Fraction，检查 `y≤0`、`A^T y+E^T z=c_obj` 及 `b^T y+f^T z≥target`。不存在浮点 LP 成功即接受的步骤。验证器重新构造目标，不能通过修改证书的目标来证明更弱结论。

## 3. 残余预算收缩

粗盒子中，每对有一个至少 1.58 的主坐标，其余坐标绝对值至多 0.603。最坏尾项 `6*(603/1580)^p/p` 小于 `10^-10`。取

```
c_p = 2*2^(-1/p),
h = 2/(c*alpha)+3*10^-10,
D >= 2/(c*alpha)+3*10^-10-6*(1-2^(-1/alpha)),
delta >= D/c_p.
```

每个 p 段 `[alpha,beta]` 保存有理的上下根界；`2/c>6 log 2` 保证用于 D 的函数 `6*2^(-1/p)+2/(cp)` 随 p 递减。这里第二个 cp 指常数 c 乘 p，而非 c_p。

对列范数 N、正的两个非对角坐标 u,v 和对角绝对值 a，得到 `a^p+((u+v)/c_p)^p≤N^p`，且 `u+v≥c_p N-D`。这是来源 `Facts` 与 `diag_cert` 的同一条件。

若已知所有 N≥n，选择 `s≤2*tlo-D/n`。对 `tau≤s/2≤sigma`，证书检查

```
tau^beta+(s-tau)^beta > 1,
sigma^beta+(s-sigma)^beta > 1.
```

由于每个幂底均在 `[0,1]`，它们对全部 p≤beta 成立，推出 `tau N<u,v<sigma N`。取下一轮 n' 和 Ab，检验

```
(Ab/n')^beta+(1-delta/n')^beta > 1,
3q <= tau*(3-n')-Ab.
```

即推出 N≥n'。严格读取前一轮 n，重复六轮。最后由来源的 `upper_round` 条件推出 N≤U，再由 `final_round` 的四个有理不等式抵达原最终盒子。16 个段完整覆盖窗口，每段长 1/64。没有把最终界当作初始假设使用。

## 4. 固定盒子的曲率与归约草案

原最终盒子对角项为 `[-1.065,-0.625]`，非对角项为 `[0.849,1.121]`。来源中与 p 无关的几何估计给出常数 9 和 4200。Hessian 系数比为

```
r_T = (14553/4528)*(133672/179139)^(p-2),
r_C = (10089/4528)*(278008/530625)^(p-2).
```

验证器在整个窗口检查

```
1 - 9*(p/2)*r_T > 0,
2c - 1/p - 2100*r_C > 0.
```

结合 `cp≤K≤p/2`，这正是总方向与各列残差方向的曲率条件。解析 Hessian 恒等式本身未由本验证器证明；它们来自 `sources/convex_box32.lean` 中 hp>2 或 hp>4 的部分，新窗口满足这些条件。

若上述源归约适配经独立审阅确认，则反例落入该凸盒子后可用同时置换的 S3 轨道平均化。平均矩阵对角为 -a、非对角为 b>0，且 `a/b∈[0.625/1.121,1.065/0.849]⊂[1/2,2]`。其亏损非负由 K 的定义保证，与反例矛盾。再沿用实三维到任意维、实到复的传递，以及循环三元组给出的 sharpness，并接上平台 cutoff 32，就得到候选 cutoff 127/4。

## 5. 验证记录

192 位与 256 位均通过相同证书。192 位输出的最小标量包络下端余量约为 `1.356e-6`；最终四个盒边界余量分别至少为 `0.0023737, 0.0023036, 0.0035973, 0.0017630`。这些显示值仅用于阅读，接受与否依据严格区间和有理数比较。

损坏覆盖、循环 witness、收缩轮次、对偶符号和二维覆盖端点的五个负测试均被拒绝。没有为 p<31.75 签发证书；浮点下探到 31.5 时，原最终盒子的对角下界条件略有失败，不能把它解释成原数学命题的反例。
